The `IServer.ClusterSlotStats*` methods expose `CLUSTER SLOT-STATS` (Redis 8.2 and later); see
[Cluster slot statistics](../ClusterSlotStats).

The server command is stable, but this library binding is new and marked experimental while the API
shape settles:

- The metric set is configuration-dependent (`cluster-slot-stats-enabled`) and documented by the
  server as extensible; the typed surface (`ClusterSlotStatsMetric`, the properties on
  `ClusterSlotStatsEntry`) may grow or change as metrics are added.
- How the per-node results are best aggregated across a cluster (today: ask each node yourself) is an
  open design question that may reshape the entry points.

Until the marker is removed, the API may change between any two versions without breaking-change
ceremony. If you acknowledge this, you can suppress the warning by adding the following to your
`csproj` file:

```xml
<NoWarn>$(NoWarn);SER012</NoWarn>
```

or more granularly / locally in C#:

``` c#
#pragma warning disable SER012
```
